# CEER2 browser compliance demo

Embedded at `/#live-demo`, standalone at `/live-demo/`. All rendering, physics,
and policy inference run on the visitor's device; no Dexlab connection or
simulation backend is required. Start loads the learned policies. The static bundle is served by GitHub Pages; no simulation backend is required.

## Controls

- Drag the highlighted left or right wrist to apply an external force (30 N cap).
- Select X/Y/Z to constrain a drag; Free drag uses the camera plane.
- Hold ±10 N for a repeatable force on the left wrist (Free defaults to X).
- X/Y/Z sliders command independent stiffness, 100–600 N/m. Presets make one
  axis soft, select that pull direction, and keep the others at 600. Anchor buttons set all axes together.
- Release, blur, pointer cancellation, and leaving the tab clear applied forces.
- Pause preserves the simulation state. Reset robot restores the standing pose
  and all policy histories. Reset settings restores [100,600,600].

## Provenance and version boundary

The deployment bundle was copied read-only from
`dexlab_steven:/home/steven/Documents/benchmark/ceer_deploy` into the sibling
`../ceer_deploy/` directory. The browser uses its actual G1 MuJoCo model,
`policy_verystiff.pt`, seven 200/400/600 EE experts, and the three axis-specific
100 N/m experts. Each model's normalization is embedded in its ONNX graph.
`policies/manifest.json` identifies every source export and displacement scale.

The public training repository was cloned into `../hiearchical_compliance/`
at commit `2826b3dc46118d5540c6a20f7ccc6ee00baf8d81`.
Composition interpolates inverse stiffness independently per Cartesian axis
in physical displacement space; the composed residual is encoded with a 0.35 m
output scale, following that repository's ten-expert MoE implementation.

**Version difference still to resolve:** the supplied deployment baseline_600
uses the older 0.15 m scale. The public repository requests a newer direct
600xyz expert with scale 0.35 m. The currently available model is explicitly
recorded with its actual scale, never silently interpreted as the newer model.
This live preview is not a reproduction of the paper's quantitative results.
Root-mode selection is not exposed in this version.

## Runtime

- MuJoCo WebAssembly 3.14.0; timestep 0.001 s, 20 physics steps per control tick.
- 50 Hz controller: high-level 311-D input, low-level 257-D input, 29 joints.
- Same joint order, gains, action scales, five-step joint history and three-step
  raw action history as the deployment code (`control.json`).
- Deterministic 0.9 action filtering; deployment delay/jitter randomization off.
- Single-thread ONNX Runtime Web supports static hosting without special headers.
- Start performs an inference parity check against stored PyTorch golden vectors.
- A fallen/non-finite state stops the simulation; reset is explicit.
- A slow device can run below real time; physics time steps are never enlarged.

## Build and serve

Run `npm ci && npm run build:demo` from the website root to refresh pinned vendor
files. Serve the website with the existing range-capable server:
`npx http-server . -a 127.0.0.1 -p 8080 -c-1`.
The files in `live-demo/` are directly deployable static assets; no bundler is
required. ONNX exports are generated by `scripts/export-browser-policies.py`
using the ceer_deploy Python environment, then copied into `policies/`.

## Validation on 2026-09-26

All eleven browser ONNX outputs matched the exported PyTorch golden vectors
(maximum absolute error 1.47e-6). A six-trial local smoke check applied +10 N
for approximately two seconds after settling. Axis displacement at commanded
100 vs 600 N/m was X: 5.31 vs 2.65 cm; Y: 7.23 vs 3.36 cm; Z: 3.94 vs 1.31 cm.
All six trials remained standing and recovered toward their unloaded pose.
These are interaction smoke checks with the older deployment baseline, not
paper benchmark measurements. Full vectors are retained in `validation.json`.
Actual mouse drag on the highlighted wrist produced a bounded external force;
mouse release cleared it. Desktop and 390 px mobile layouts were inspected.
